Data Management

Import historical data from CSV files for extended backtesting

Import CSV Data
How to get historical data:
  1. MT5 History Center: Open MT5 → Tools → History Center → Select XAUUSD M1 → Click "Export"
  2. MT5 Chart Export: Open M1 chart → File → Save As → CSV
  3. Third-party: Download from data providers (Dukascopy, HistData.com, etc.)
Supported formats: MT5 export (tab/comma separated), or any CSV with Date, Time, Open, High, Low, Close, Volume columns. Files are auto-detected. UTC timezone is assumed if not specified.
Naming: Files are saved as SYMBOL_TIMEFRAME_yourname.csv and automatically merged with MT5 live data during backtests.
Download from MT5

Try to download all available history from your MT5 broker. This uses a different fetching method (copy_rates_from_pos) that may access more data than the standard range request.

Note: MetaQuotes-Demo typically limits M1 data to ~90 days. If this doesn't provide enough data, use the CSV import above to load data from external sources (MT5 History Center export, Dukascopy, HistData.com, etc.).
Extract from IBKR (Interactive Brokers)

Download historical data directly from your IBKR TWS or Gateway. Supports XAUUSD (Gold), EURUSD, GBPUSD, USDJPY. Auto-detects contract type.

0%
Setup:
  • TWS Paper Trading: port 7497 (default) | TWS Live: port 7496
  • IB Gateway Paper: port 4002 | IB Gateway Live: port 4001
  • Enable API connections in TWS: File → Global Configuration → API → Settings → check "Enable ActiveX and Socket Clients"
  • Gold contract is auto-detected: tries Forex (IDEALPRO) → CFD (SMART) → Futures GC (COMEX)
Estimated times (M1): 1 month ~45s | 3 months ~2.5 min | 6 months ~5 min | 12 months ~9 min
Download from Dukascopy (Free Data Feed)

Download free historical M1 tick data from Dukascopy's public data feed. Tick data is aggregated into M1 candles. Supports XAUUSD, EURUSD, GBPUSD, USDJPY, XAGUSD, US500. VPN may be required in some regions (e.g. Turkey).

0%
Notes:
  • Dukascopy provides free tick data going back to ~2003 for major pairs and ~2012 for Gold
  • Data is downloaded as ticks and aggregated into M1 candles (mid price = (ask+bid)/2)
  • Higher timeframes (M5, M15, H1, H4) are auto-resampled from M1 during backtests
  • Dukascopy may be blocked in some countries — use a VPN if the connection test fails
Estimated times: 1 month ~5 min | 6 months ~30 min | 1 year ~1 hour | 4 years ~4 hours

How Data Merging Works
1. CSV Data (Historical)

Upload CSV files with older historical data (e.g., Jan-Sep 2025). This extends your data beyond the broker's ~90 day limit.

2. Auto-Merge

When you run a backtest, the system automatically merges CSV data with live MT5 data. Overlapping bars are deduplicated (MT5 preferred for recent data).

3. Extended Backtests

Now you can run 6-12 month backtests with 200+ trades, enough data to train reliable ML models.
